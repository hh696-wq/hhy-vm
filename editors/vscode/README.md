# HHY Language Support

Syntax highlighting, comments, bracket handling, folding, indentation and snippets for `.hhy` files.

The grammar is generated from the HHY repository's shared editor syntax source. This extension does not start the HHY runtime and does not provide diagnostics or formatting in version 0.1.0.

See the repository `editors/README.md` for installation and development instructions.
