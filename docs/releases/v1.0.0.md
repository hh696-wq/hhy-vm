# HHY Language 1.0.0

**Pipe Everything.** HHY 1.0.0 is the first stable release of the flow-first
system scripting language for files, processes, networks, and structured data.

## Download

Choose the archive matching your computer:

- `hhy-1.0.0-darwin-arm64.tar.gz` — Apple silicon macOS
- `hhy-1.0.0-linux-x86_64.tar.gz` — 64-bit Intel/AMD Linux
- `hhy-1.0.0-linux-arm64.tar.gz` — 64-bit ARM Linux

The archives include the HHY executable, required non-system runtime libraries,
documentation, license notices, build metadata, and runnable examples.

```sh
tar -xzf hhy-1.0.0-PLATFORM-ARCH.tar.gz
cd hhy-1.0.0-PLATFORM-ARCH
./bin/hhy --version
./bin/hhy run examples/07-language-basics.hhy
```

Keep `bin/` and `lib/` together. To make `hhy` available in every terminal,
add the archive's absolute `bin` directory to `PATH`.

Verify the download with the matching `.sha256` file or the combined
`SHA256SUMS` manifest before running it.

## Highlights

- Stable variables, scopes, collections, functions, closures, control flow,
  modules, and structured errors.
- Lazy, single-consumption Flow pipelines with bounded collection and execution.
- Native filesystem, text, Regex, JSON, CSV, process, HTTP, watch, and unit APIs.
- Ordered bounded `parallel(n)`, cancellation, backpressure, and resource limits.
- `run`, `repl`, `check`, `fmt`, `ast`, `tokens`, and dry-run execution plans.
- Apache License 2.0.

See `docs/HHY_V1.md` for the frozen language contract and
`docs/KNOWN_LIMITATIONS.md` for the supported-platform boundary.
