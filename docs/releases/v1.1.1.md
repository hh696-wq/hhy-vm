# HHY Language 1.1.1

HHY 1.1.1 is the performance diagnostics and Runtime boundary-stability release.
It preserves the frozen v1.0 language contract and the v1.1 Process Extension
Protocol.

## Highlights

- Added `hhy profile` with low-overhead CPU sampling, logical function and builtin
  call counts, managed-Heap allocation attribution, peak Heap observation, and
  text or JSON reports.
- Added a runnable recursive algorithm example for establishing repeatable
  interpreter performance baselines.
- Defined the v1.1.1 optimization cycle around measured interpreter hotspots and
  GC, memory, recursion, collection, and runtime-limit boundary tests.
- Kept limit breaches on the structured-error path so optimization work does not
  trade predictable failure for process crashes.
- Updated the website CLI reference and simplified the language/VM roadmap to two
  future stages: official extension distribution/tooling, then the conditional
  ecosystem and Native ABI decision.

## Compatibility

HHY scripts compatible with 1.1.0 remain compatible with 1.1.1. The extension
wire protocol remains Protocol 1; no public Native ABI is introduced.
