# HHY 1.2.1

HHY 1.2.1 closes the public v1.2 extension-distribution loop with reproducible, offline-capable installation and safe rollback.

## Extension environment

- Schema-versioned `hhy.lock` records the exact signed Registry snapshot, host target, root identity, package graph, versions, dependencies, and file digests.
- `hhy fetch --locked` creates an index-digest-addressed cache and verifies every copied payload.
- `hhy install --locked` rejects Registry drift; `--offline --locked` installs only from the verified cache snapshot.
- `hhy install --upgrade` preserves the previous verified version before atomically switching the active tree.
- `hhy rollback <package>` atomically restores the previous version and retains the displaced version as rollback history.
- `hhy doctor extensions` verifies active package integrity and can also check lock/cache consistency.
- Non-sensitive install, upgrade, rollback, and removal audit events are retained in the extension home.

## Compatibility

The frozen HHY v1 language, Pipe, Value, Stream, Error, cancellation, resource-limit, and Process Extension Protocol 1 semantics are unchanged.

## Release gate

The GitHub Release is the final step only after GitHub Actions passes for Linux, macOS, and Windows and all corresponding release artifacts have been produced and checked.
