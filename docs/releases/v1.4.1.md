# HHY v1.4.1 — HTTP Server 与 Router

> 记录整理日期：2026-09-09。
> 状态：能力里程碑；统一于 2026-09-03 随 v1.4.3 交付，无独立发行 tag。

## 交付内容

- hhy serve 提供常驻 HTTP/1.1 应用。
- 精确路径与 :param 路由、解码 Query、Header、Cookie 和有界文本/二进制请求体。
- JSON/text/HTML/自定义响应、重定向、稳定错误及错误后的恢复。

## 兼容性与限制

TLS 与 HTTP/2 交给反向代理或负载均衡器；不提供 WebSocket。

## 验收与证据口径

正式说明记录 Router、Query、404/405/413/500 及错误后恢复；百万次请求为整个 v1.4.3 的合并验收，非本阶段独立压测。
