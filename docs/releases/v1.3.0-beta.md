# HHY v1.3.0-beta (development draft)

This is a development record, not a published release. `VERSION` remains
`1.3.0-alpha` until the beta exit criteria are complete.

## Implemented in the beta branch

- Adds experimental `hhy run --engine ast|bytecode` selection; AST remains the default.
- Compiles and verifies Bytecode before the Bytecode execution path can run.
- Builds a bounded instruction-pointer, operand, and frame execution plan.
- Derives the Bytecode frame budget from `RuntimeLimits.max_recursion`.
- Reuses the existing Runtime as the single implementation of Values, closures/upvalues,
  structured errors, GC roots, cancellation, Streams, effects, and resource limits.
- Adds local AST/Bytecode conformance tests for stdout, stderr, and exit status.
- Passes Release and ASan/UBSan test suites locally.

## Still required before beta publication

- Replace the compatibility bridge with the dedicated opcode dispatch loop.
- Expand conformance to the complete valid and invalid-runtime fixture matrix.
- Expand opcode-level profiler aggregation beyond the current engine, HHY
  function, and source-position reporting.
- Complete GC stress, fuzz, failure injection, and three-platform CI evidence.
- Keep Bytecode opt-in; do not change the default engine during beta.

GitHub Actions and GitHub Release publication are intentionally deferred until
several consecutive development stages are ready for one coordinated validation
and release pass.
