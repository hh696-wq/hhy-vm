# HHY v1.7.2 — 整数 MIR、反馈特化与局部标量替换

> 记录整理日期：2026-09-09。
> 状态：工程子阶段；2026-09-08 随产品 v1.7.0 交付，并非新的独立补丁发行。

## 交付内容

- 编译边界建立有界整数寄存器 MIR；最多 64 个目标反馈槽、每目标 8 参数与 64 指令。
- 连续 8 次 Int 调用后进入特化，每次入口 guard；累计类型不匹配触发停用，算术失败在原操作恢复通用错误。
- 符合条件的单个直接索引局部 List 使用标量寄存器，但按原顺序求值所有元素并保留分配预约。

## 兼容性与限制

HHY_FEEDBACK_SPECIALIZATION=1 与 HHY_SCALAR_REPLACEMENT=1 默认关闭。不支持通用逃逸分析、任意聚合值标量化或物理分配消除；未知形态回退。

## 验收与证据口径

以 v1.7.0 统一验收为准。静态 IR、整数 MIR 与跨平台预算分别有专项证据；本页按工程职责拆分说明，不意味着曾为此子阶段单独构建或发布资产。
