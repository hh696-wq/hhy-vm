# HHY v1.4.3 — Web Runtime 正式发行

> 记录整理日期：2026-09-09。
> 状态：正式发行：2026-09-03；统一交付 v1.4.0–v1.4.3 能力。
> 本地发行 tag：`v1.4.3`；对应提交：`bee8a5415feab45b933dfe65a318b88b391559b8`。

## 交付内容

- 包含 Embedding、请求隔离、HTTP/1.1 Router、Middleware、静态文件、上传、CORS、cookie、gzip 和开发热重载。
- 增加有背压的 chunked 响应、SSE、大文件流式发送与 byte Range。
- Prefork 多 Worker、重启监督、结构化 access/error 日志和 Prometheus 请求/错误/字节/耗时指标。

## 兼容性与限制

TLS/HTTP2 由代理承担；WebSocket 不在 v1.4 范围。131.439 秒、7,608.1 req/s 仅是指定验收宿主的短请求负载，不能外推其他平台或替代 24 小时长稳。

## 验收与证据口径

原说明记录 100,000 次嵌入调用、16 并发的 1,000,000 次 loopback HTTP 请求且零失败，以及 Web 端到端、Release/Debug sanitizer、双引擎、文档、网站构建和既有性能门禁。未提供 24 小时稳定性完成证据。
