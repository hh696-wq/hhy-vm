# HHY v1.7.3 — Compiler 验证、观测与预算闭环

> 记录整理日期：2026-09-09。
> 状态：工程子阶段；2026-09-08 随产品 v1.7.0 交付，并非新的独立补丁发行。

## 交付内容

- pass timing、IR/Bytecode/MIR 大小、变换与拒绝原因可观测。
- 三路径差分、变形/变异/fuzz、源码错误、取消、精确托管配额和开关组合进入验收。
- 逐平台保存编译、端到端运行、代码量与资源预算原始样本；与当前直接 Bytecode 对照。

## 兼容性与限制

编译 ≤ 2×直接编译 + 500μs、运行 ≤ 95%、托管分配 ≤ 101%，另检查代码尺寸和 MIR 存储上限。真实负载收益未达标，默认准入维持拒绝；不以合成样例抵消真实回归。

## 验收与证据口径

以 v1.7.0 统一验收为准。静态 IR、整数 MIR 与跨平台预算分别有专项证据；本页按工程职责拆分说明，不意味着曾为此子阶段单独构建或发布资产。
