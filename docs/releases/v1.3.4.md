# HHY v1.3.4 — VM 数据路径与环境访问

> 记录整理日期：2026-09-09。
> 状态：历史工程阶段；对应能力可在 v1.3.5 正式发行说明中核对。

## 交付内容

- 补齐已解析的 local-slot 元数据与可验证的 subtree 导航，减少重复环境查找。
- 通过可复用调用帧、低分配 Stream closure 调用和整数快路径降低执行成本。
- 保留 AST oracle，为后续默认引擎切换提供差分与性能判定基础。
