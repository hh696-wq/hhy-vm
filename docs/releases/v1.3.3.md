# HHY v1.3.3 — 原生 Opcode 执行闭环

> 记录整理日期：2026-09-09。
> 状态：历史工程阶段；对应能力可在 v1.3.5 正式发行说明中核对。

## 交付内容

- 正常 Bytecode 路径直接执行经验证的 Opcode，不再把节点桥接回 AST evaluator。
- 覆盖表达式、声明、控制流、函数、闭包、错误、Pipe、集合、导入及导出。
- 保持源码映射、取消、资源限制与共享 Runtime/Contract 边界。

## 兼容性与限制

本地没有 v1.3.3 tag，VERSION 历史也未单列该版本。路线图曾标为“已发布”，但现有证据不足以确认独立发行日期、资产或 commit；本页不虚构独立下载入口。直接执行仍是结构化 Opcode 模型，不宣称平坦寄存器 VM。
