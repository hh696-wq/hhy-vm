# HHY v1.3.9

Released on 2026-09-01.

## Observation and resource consistency

- Normal execution and Profiler use the same optimization decision and semantic
  path.
- Profile JSON schema 2 records bounded optimization decisions, stable reasons,
  Stream Kernel versions, and actual kernel/opcode names.
- CPU hotspots identify fused kernels; managed allocations from fused collect
  are attributed to `<stream-collect>`.
- Cancellation, Heap accounting, error behavior, and output are compared across
  ordinary and profiled execution.
- A blocking profiler-overhead report remains machine-readable.

## Performance methodology correction

The JSON engine gate now uses a sustained 500-iteration workload with paired,
interleaved samples. The 1.10 threshold was not weakened; the longer workload
removes fresh-process timer noise from the engine comparison.
