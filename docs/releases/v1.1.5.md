# HHY Language 1.1.5

HHY 1.1.5 upgrades the safe Spider into a resumable collector and adds bounded
browser rendering while preserving the frozen v1.0 language contract and
Process Extension Protocol 1.

## Highlights

- Added atomically persisted crawler checkpoints containing the frontier,
  fingerprints, pages, counters, and depth, with strict configuration-key
  validation before resume.
- Added `send_to(HttpRequest, Path)` to stream bounded HTTP responses directly
  into a sibling temporary file and atomically publish the completed result.
- Added an optional standalone Playwright renderer for authorized JavaScript
  pages. Domain, redirect, subresource, DNS, and private-address checks remain
  outside the side-effect-free HTML extension.
- Added deterministic acceptance coverage for partial runs, resume, streamed
  responses, rendered content, and default-deny private-network behavior.
- Added Windows x86_64 MSYS2 build and core Parser/Runtime smoke evidence.
  Windows remains an MSYS2 POSIX target rather than a native Win32 archive.

## Compatibility and boundaries

Existing HHY programs remain compatible. `send` keeps its existing in-memory
response behavior; callers opt into file streaming through `send_to`.

Both HTTP paths retain the configured response-size limit. Crawler checkpoints
are single-process batch snapshots, not a distributed queue. The Playwright
renderer requires Node.js and Chromium, and hostile browsing still requires an
OS-level network sandbox in addition to application checks.

See `docs/KNOWN_LIMITATIONS.md` for the complete public boundary.
