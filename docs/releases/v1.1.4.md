# HHY Language 1.1.4

HHY 1.1.4 turns the bounded static collector into a safe recursive Spider while
preserving the frozen v1.0 language contract and Process Extension Protocol 1.

## Highlights

- Added `url_resolve`, backed by libcurl's URL API, for relative-reference
  resolution, dot-segment removal, fragment removal, host normalization, default
  port removal, and stable request fingerprints.
- Added an opt-in HTTP private-network guard that validates every resolved socket
  connection, including redirect targets, before connecting.
- Upgraded `my-crawler` with HTML link discovery, a depth frontier, domain and
  path allowlists, page/depth/frontier/link limits, and pre-admission fingerprint
  deduplication.
- Added a deterministic three-level fixture and a negative loopback SSRF test.
- Updated the bilingual crawler tutorial with implemented capabilities, limits,
  configuration, and verified output.

## Compatibility

Existing HHY scripts remain compatible. General HTTP requests retain their
previous behavior unless `allow_private_networks: false` is selected. The
official crawler selects the safe mode by default; local fixtures opt in
explicitly.
