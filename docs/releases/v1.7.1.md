# HHY v1.7.1 — 保守静态优化

> 记录整理日期：2026-09-09。
> 状态：工程子阶段；2026-09-08 随产品 v1.7.0 交付，并非新的独立补丁发行。

## 交付内容

- 六个独立 pass：fold、constant-propagation、copy-propagation、peephole、unreachable、dce。
- 每个 pass 后独立 verify；传播验证来源、定义顺序、作用域和 shadowing。
- 保留 Error、副作用、取消点、声明/帧容量与必要分配；超出代码尺寸预算整体回退。

## 兼容性与限制

HHY_COMPILER=ir 启用；HHY_COMPILER_DISABLE 可禁用指定 pass 或 all。只关闭 pass 不等于回到直接编译器，也不关闭独立 MIR 特化。

## 验收与证据口径

以 v1.7.0 统一验收为准。静态 IR、整数 MIR 与跨平台预算分别有专项证据；本页按工程职责拆分说明，不意味着曾为此子阶段单独构建或发布资产。
