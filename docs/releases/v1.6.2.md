# HHY v1.6.2 — 条件式 Inline Cache

> 记录整理日期：2026-09-09。
> 状态：工程阶段；2026-09-08 统一随 v1.7.0 交付，无独立 v1.6.x 发行 tag。

## 交付内容

- HHY_PROFILE_LOOKUPS=1 记录 binding/builtin、通用 call target 和 Map 访问反馈。
- HHY_MAP_INLINE_CACHE=1 开启单态 slot 提示；每次校验当前键并读取当前值。
- 有界 site 表、dropped 计数和 megamorphic fallback；不保留可解引用的 Map/Value/Closure 指针。

## 兼容性与限制

实验默认关闭。PIC、hidden shape、持久名字/builtin 缓存尚未准入；高候选命中率不等于端到端收益。
