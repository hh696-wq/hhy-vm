# HHY v1.3.8

Released on 2026-09-01.

## Versioned Stream Kernel IR

- Moved Runtime expression-shape recognition into the Compiler.
- Compiler emits versioned Stream Kernel IR for supported closure shapes.
- Independent verification covers opcode validity, type flow, stack shape,
  constants, result type, terminal return, and source instruction ownership.
- Runtime executes only verified kernels and never inspects AST expression
  shapes for specialization.
- Dynamic or unknown closures fall back without loss to general Bytecode.

## Verification

Three-path differential/metamorphic tests, corrupted-kernel tests, fuzzing,
sanitizers, real workloads, and four-platform publication passed.
