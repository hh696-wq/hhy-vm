# HHY 1.1.8

HHY 1.1.8 establishes gradual Runtime governance without changing language or
Runtime behavior.

## Runtime boundaries and ownership

- Moves the default resource-limit policy into `runtime_limits.c`, the first
  behavior-preserving Runtime module boundary.
- Defines internal borrowed, managed-scanned, managed-atomic and native-owned
  vocabulary without exposing a public C ABI.
- Adds a static governance check for the limits boundary, allocation annotations,
  Runtime-owner teardown and managed `Value` storage.
- Documents the ordered extraction policy so later work moves one stable
  responsibility at a time.

## Performance gate

- Converts the reproducible benchmark report into a blocking quality gate.
- Checks reviewed absolute ceilings and ratios normalized to CLI startup.
- Requires an explicit, explained review to change the committed performance
  budget.

## Compatibility

HHY syntax, callable contracts, diagnostics, exit codes, default resource limits
and execution behavior are unchanged. No tag or GitHub Release is created for
this development checkpoint.
