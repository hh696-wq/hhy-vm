# HHY v1.3.10

Released on 2026-09-01.

## Evidence-gated Bytecode cache governance

- Added `hhy bytecode --metrics` schema-1 JSON for compile+verify and
  verify+execution-plan timing.
- Added a fixed five-workload, 21-sample paired fresh-process decision report.
- Local macOS arm64 measurements found compile+verify medians of
  0.004–0.012 ms, only 0.0078%–0.1341% of cold Bytecode-run wall time.
- The joint admission threshold is 1 ms and 20%. No workload triggered it, so
  v1.3.10 intentionally ships no process cache, disk cache, or `.hhyc` loader.
- Unverified external Bytecode remains rejected.
- The future-admission contract requires complete source/dependency/version/
  feature/target/security fingerprints, checksum, bounded decoding, the full
  Verifier, execution-plan verification, safe invalidation/recompile, atomic
  writes, size limits, and protection from untrusted symlink traversal.

## Verification

The machine-readable decision is uploaded with CI evidence. The full Release
and Debug suites, ASan/UBSan, GC stress, 1,000-input fuzz smoke, real workloads,
performance gates, website build, four-platform archives, individual checksums,
and SHA256SUMS all passed.
