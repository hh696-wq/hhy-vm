- v1.4.0–v1.4.2 为 Web 能力里程碑，统一随 v1.4.3 发行。
- v1.6.0–v1.6.3 与 v1.7.1–v1.7.3 为工程子阶段，统一随产品 v1.7.0 交付；这些文件不是待安装的新补丁版本。
- v1.3.3/v1.3.4 的原路线图写有独立发布结论，但本地没有相应 tag，VERSION 历史也未单列。新增记录只说明可从 v1.3.5 核对的合并能力，独立发行日期、资产及提交保持待核实。
- v1.8/v2.0 尚为规划，不生成虚构发行说明；后续目标见[主路线图](../ROADMAP.md)。
- `database-v1.0.0` 是扩展的独立 tag，不占用 HHY Core 版本编号；其[发行说明](../../extensions/database/RELEASE_NOTES.md)、[变更记录](../../extensions/database/CHANGELOG.md)和[验收](../../extensions/database/ACCEPTANCE.md)保留在扩展目录。
- 新补文档为依据已有资料整理的中文摘要，同一文件内合并的英文发行说明及专项证据保留详细内容。以后更新版本状态时同步本索引，不覆盖历史测量条件，不把阶段完成写成默认性能准入。
- `docs/releases/` 纳入 Core 仓库；更新文档不改变既有 Release 资产。
