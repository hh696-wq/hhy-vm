# HHY Language 1.1.3

HHY 1.1.3 is a Runtime correctness and performance hardening release. It
preserves the frozen v1.0 language contract and Process Extension Protocol 1.

## Highlights

- Moved all reviewed temporary and persistent buffers that retain managed
  `Value` or pointer references into explicitly scanned BDWGC storage.
- Added deterministic Release-mode GC pressure regression coverage for Stream
  collection, sorting/grouping, JSON arrays/objects, CSV rows, and distinct
  state, plus a static allocator ownership guard.
- Replaced quadratic `distinct` lookup with an insertion-ordered open-addressing
  hash set and added hash indexes for wide Map lookup and JSON duplicate keys.
- Made unavailable host process snapshots return a diagnostic
  `ProcessError(HHY_PROCESS_SNAPSHOT)` instead of an ambiguous empty Stream.
- Added CPU sampling period, data quality, and warnings to JSON profiler output.
- Corrected historical release evidence and added a complete remediation report
  with local sanitizer and three-platform CI proof.

## Compatibility

HHY scripts and Protocol 1 extensions compatible with 1.1.2 remain compatible
with 1.1.3. No language syntax, wire protocol, or public Native ABI changes are
introduced.
