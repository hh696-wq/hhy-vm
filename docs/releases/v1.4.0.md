# HHY v1.4.0 — Embedding 与请求隔离

> 记录整理日期：2026-09-09。
> 状态：能力里程碑；统一于 2026-09-03 随 v1.4.3 交付，无独立发行 tag。

## 交付内容

- Opaque HhyApplication/HhyContext、JSON ABI 边界和安装用 libhhy.a/头文件。
- 应用源码/Bytecode 一次加载，重复 hhy_call；支持 AST/Bytecode 选择。
- 请求/嵌入调用拥有明确的 Context 与清理边界。

## 兼容性与限制

不公开 Runtime 内部结构体或稳定 Native ABI；应用复用不等于请求之间共享可变资源。

## 验收与证据口径

正式说明记录单个加载 Context 的 100,000 次调用与 AST/Bytecode 输出对照。
