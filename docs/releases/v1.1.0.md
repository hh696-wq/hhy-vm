# HHY Language 1.1.0

HHY 1.1.0 adds the first stable local Process Extension workflow while preserving
the HHY 1.0 language contract.

## Highlights

- Local `hhy install`, `hhy list`, and `hhy remove` commands.
- SHA-256 verification when installing and loading extension packages.
- Isolated process handshake, callable registration, calls, structured errors,
  shutdown, and namespace validation.
- Required extension author attribution and capability review in the CLI.
- Official C11 `sample` and `database` packages included in release archives.
- PostgreSQL/MySQL parameterized ping, bounded query, execute, and atomic
  transaction support in `database` 0.2.0.

## Scope

Version 1.1 supports local package paths only. Remote registries, publisher
signature verification, dependency resolution, streaming extension results,
connection handles/pools, and opaque handles remain outside this release.

Database transactions accept 1–100 `INSERT`, `UPDATE`, or `DELETE` statements.
DDL and result-returning queries are deliberately excluded from the first
transaction API.

See `docs/EXTENSION_PROTOCOL_V1.md` and `docs/KNOWN_LIMITATIONS.md` for the exact
protocol subset and public limitations.
