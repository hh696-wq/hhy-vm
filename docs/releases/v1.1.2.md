# HHY Language 1.1.2

HHY 1.1.2 adds bounded static-HTML collection while preserving the frozen v1.0
language contract and the v1.1 Process Extension Protocol.

## Highlights

- Added the official `html` 0.1.0 process extension, backed by Lexbor, with
  bounded CSS-selector text, attribute, existence, and schema extraction APIs.
- Added the runnable `my-crawler` practical project with project-local extension
  initialization, bounded parallel fetching, timeout/retry, atomic JSON output,
  deterministic local fixtures, and a real hhylang.dev crawl configuration.
- Added bilingual website chapter 21 for the HTML extension and crawler framework,
  with explicit buffered-response and static-document boundaries.
- Added Lexbor dependency declarations, notices, CI coverage, and release archive
  packaging for macOS arm64, Linux x86_64, and Linux arm64.

## Compatibility

HHY scripts and Protocol 1 extensions compatible with 1.1.1 remain compatible
with 1.1.2. The HTML extension transports only JSON-shaped values and introduces
no public Native ABI or opaque DOM handles.
