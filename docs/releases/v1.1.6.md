# HHY Language 1.1.6

HHY 1.1.6 establishes the stable engineering baseline for the next language and
extension-tooling iterations without changing the frozen v1 language semantics.

## Highlights

- Adds explicit host-capability probes for process snapshots and loopback socket
  binding. Restricted environments now emit stable skip reason codes instead of
  reporting ambiguous Runtime failures.
- Separates GitHub Actions quality/performance evidence, native Runtime/release
  validation, and practical-project acceptance into independently attributable
  jobs.
- Adds a reproducible JSON performance baseline for CLI startup, representative
  Flow execution, a 100k-item core Flow, and JSON processing.
- Adds `make quality` and `make benchmark` entry points for the local and CI
  validation loops.
- Keeps release identity, documentation, website metadata, archive checksums,
  and release evidence aligned on version 1.1.6.

## Compatibility

- No syntax, Value, Pipe, Stream, Error, extension protocol, or exit-code
  semantics changed.
- Local-path extension installation and Protocol 1 synchronous calls remain
  compatible with v1.1.5.
- The Homebrew formula continues to reference the latest already-published
  archive until the v1.1.6 release asset digest is available.
