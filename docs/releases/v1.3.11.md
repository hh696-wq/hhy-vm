# HHY v1.3.11

Released on 2026-09-02.

## Runtime robustness

- Structured HHY Error values are now fully constructed in local storage before
  being published to the Runtime state.
- Invalid regular expressions return the existing deterministic `ValueError`
  instead of exposing a partially initialized error map.
- The exact coverage-guided fuzz input that found the crash is retained in the
  permanent corpus and runs on both Linux release architectures.

## Reproducible performance evidence

- The fixed one-million-item AST/Bytecode workload now declares the same 1 GiB
  Runtime memory budget for both engines.
- Normal HHY programs retain the existing default Runtime memory limit.
- Resource-limit behavior remains covered independently from performance
  measurement.

## Verification

- Local ASan/UBSan execution of the original reproducer passed.
- `make quality` and the six-workload performance regression gate passed.
- Linux x86_64 and Linux arm64 coverage-guided fuzzing passed.
- macOS arm64 sanitizer/fuzz smoke, Windows x86_64 smoke, all Release suites,
  practical-project acceptance, checksummed archives, and required notices
  passed.
