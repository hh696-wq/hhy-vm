# HHY v1.3.7

Released on 2026-09-01.

## Specialization hardening

- Replaced magic specialization kinds with named operations and centralized
  metadata.
- Unified stack effects, eligibility, overflow/division error rules, and stable
  fallback reasons.
- Made each specialization independently verifiable, disassemblable, and
  explainable.
- Added AST/general-Bytecode/specialized-Bytecode differential tests,
  metamorphic tests, damaged-plan rejection, and reliable fallback coverage.

## Verification

Release, Debug ASan/UBSan, fuzzing, real workloads, four-platform archives,
per-asset SHA-256 files, and SHA256SUMS passed before publication.
