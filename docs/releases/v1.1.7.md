# HHY Language 1.1.7

HHY 1.1.7 adds the diagnostics and editor baseline without changing the frozen
v1 language or Runtime semantics.

## Highlights

- Adds `hhy check --format json` with a versioned diagnostics schema, stable
  codes, severities and zero-based source ranges.
- Adds `hhy contracts --format json` so tooling consumes the same callable
  contracts as the Checker and Runtime.
- Adds a dependency-light HHY language server with diagnostics, canonical
  formatting, local definition navigation, Contract-aware Hover and completion.
- Updates the VS Code extension to 0.2.0 and connects it through the standard
  VS Code language-client protocol.
- Adds protocol-level LSP tests and runs editor verification in `make quality`.

## Compatibility

- Text diagnostics remain the default CLI behavior.
- Pipe, Value, Stream, Error, exit-code and Process Extension Protocol semantics
  are unchanged.
- No Git tag, GitHub Release, Native ABI or Bytecode format is introduced.
