# HHY v1.6.3 — GC 与 Scheduler 条件评估

> 记录整理日期：2026-09-09。
> 状态：工程阶段；2026-09-08 统一随 v1.7.0 交付，无独立 v1.6.x 发行 tag。

## 交付内容

- 独立 resource probe 采集 Boehm allocation、collection、pause 与 retained estimate。
- 分别记录父进程/Worker、窗口内/最终强制 GC、退出后/live Context 的范围。
- 审核真实项目、取消和有界有序 parallel 行为，保留现有 conservative GC 与进程调度。

## 兼容性与限制

未实现新 GC 或 async scheduler。retained estimate 不是精确 live-set；缺生产预算或 promotion/write-barrier 成本时决策保持未知，不把本地 pause 当成最坏延迟 SLA。

## 验收与证据口径

专项日志保留该阶段本地配置、测试与测量范围；统一产品的四平台 CI/发行结果见最终归档。本次补文档没有重新执行这些历史验收，默认性能准入仍按具体实验独立评估。
