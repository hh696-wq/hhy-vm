# HHY v1.6.0 — VM dispatch 画像

> 记录整理日期：2026-09-09。
> 状态：工程阶段；2026-09-08 统一随 v1.7.0 交付，无独立 v1.6.x 发行 tag。

## 交付内容

- HHY_PROFILE_DISPATCH=1 显式启用 opcode 单项/pair/triple 画像，使用版本化 JSON 和固定容量表。
- 统计递归执行域切换并隔离序列，不持有 managed pointer；普通 run 不创建画像表。
- 提供配对 fresh-process 评估工具与输出/取消/错误验证。

## 兼容性与限制

动态调用转移不是平坦指令邻接；纯 dispatch 成本尚未分离，superinstruction / richer instruction selection 候选未准入。
