# HHY v1.6.1 — 调用、Closure 与异常展开

> 记录整理日期：2026-09-09。
> 状态：工程阶段；2026-09-08 统一随 v1.7.0 交付，无独立 v1.6.x 发行 tag。

## 交付内容

- 版本化 call plan、逻辑 RuntimeCallFrame、exception region 与 unwind 动作表。
- 有界 Env 帧池实验；共享词法环境/slot 与可变闭包别名保持原语义。
- 调用布局、异常表、帧池和调用展开独立关闭；宿主参数转换保护与原生文件资源清理修复始终生效。

## 兼容性与限制

机器栈仍使用 C 调用及 setjmp/longjmp；不提供 DWARF/SEH、trampoline 或尾调用消除。实验默认关闭，不能把本地正确性与有限测量当作跨平台提速准入。

## 验收与证据口径

专项日志保留该阶段本地配置、测试与测量范围；统一产品的四平台 CI/发行结果见最终归档。本次补文档没有重新执行这些历史验收，默认性能准入仍按具体实验独立评估。
