# HHY v1.7.0 — Optimizing Compiler 与 Runtime 实验

> 记录整理日期：2026-09-09。
> 状态：正式发行：2026-09-08；统一包含 v1.6 Runtime 与 v1.7 四个 Compiler 工程子阶段。
> 本地发行 tag：`v1.7.0`；对应提交：`8fb0b8f71892ec281256027530f065d7de5921af`。

## 交付内容

- 整程序结构化 HIR、callable CFG region、独立 verifier、IR dump 和 IR→Bytecode 后端。
- 六个可单独关闭并逐 pass 验证的静态优化：fold、constant/copy propagation、peephole、unreachable、DCE。
- 有界整数寄存器 MIR、真实参数反馈、逐次 guard、原算术源码位置的 deopt，以及单个直接索引局部 Int List 标量替换。
- 包含 v1.6 调用布局、异常表、帧池、调用展开和单态 Map slot 实验；不包含未准入的新 GC、async 或 superinstruction。

## 兼容性与限制

默认仍为直接 Bytecode。HHY_COMPILER=ir、HHY_FEEDBACK_SPECIALIZATION=1、HHY_SCALAR_REPLACEMENT=1 均需显式启用；未知类型、捕获、动态调用与逃逸形态回退。标量替换保留原始 GC/配额分配预约，不代表物理堆分配消除。真实负载未过默认收益门槛。

## 验收与证据口径

归档记录实现候选 8fb0b8f 的四平台 CI 34197497786、数据库 34197497779 与最终发行重试 34199886300 成功。包含语义/资源差分、verifier 变异、sanitizer、fuzz、真实项目与正式包 smoke；重试前后九个 Core 资产 digest 不变。正确性和合成样例预算通过，不等于真实负载普遍加速。
