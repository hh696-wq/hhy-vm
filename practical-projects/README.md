# HHY practical projects

Complete, self-tested applications built with HHY:

- [FlowGuard](flowguard/README.md) — a CI/CD-ready project quality gate.
- [DataFlow ETL](dataflow-etl/README.md) — a CSV/JSON enrichment and reporting pipeline.
- [Asset Governance](asset-governance/README.md) — a safe asset auditing and remediation workflow.
- [Hong Kong Film Companies](hong-kong-film-companies/README.md) — concurrent Wikipedia research exported to CSV.
- [Algorithm Benchmarks](algorithm-benchmarks/README.md) — verified HHY timing comparisons with Go, Python, and PHP.

Each project includes deterministic fixtures and a `self-test.sh` script that can be run from the repository root.
