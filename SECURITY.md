# Security reporting

Please do not post credentials, private data, or an unpatched exploit in a public
issue. For sensitive reports, contact the maintainer using the contact information
in [README.md](README.md), or use GitHub's private vulnerability reporting feature
if it is enabled for this repository.

Include the affected HHY version, OS/architecture, minimal reproducer, actual and
expected behavior, and relevant configuration with secrets removed. Keep the
original diagnostic output available, but redact tokens, database credentials,
private endpoints and user data before sharing.

Current platform and capability boundaries are documented in
[KNOWN_LIMITATIONS.md](docs/KNOWN_LIMITATIONS.md). This project does not promise a
fixed security response time or maintenance window for historical versions.
